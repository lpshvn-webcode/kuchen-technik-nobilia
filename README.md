# Küchen Technik × Nobilia

Адаптивный лендинг на русском языке. Статический HTML, CSS и JavaScript; сборка и сервер приложений не требуются.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root). index.html лежит в корне. Все пути относительные, поэтому сайт работает по адресу https://OWNER.github.io/REPOSITORY/.

Для локального просмотра:

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173.

## Возможности

- Четыре кухни, предоставленные заказчиком, в двух встречных движущихся лентах: одно фото и название в карточке.
- Интерактивный мини-шоурум: полноэкранный фото-тур с параллаксом, переходами между точками и карточками деталей. На desktop карточки открываются сбоку, на mobile — снизу.
- Конструктор: независимый подбор верхних фасадов, столешницы с фартуком и нижних фасадов. Три отделки каждой зоны, 27 сочетаний; выбранное сочетание передаётся в контекст обращения.
- Мобильное меню, FAQ, клавиатурная навигация.
- Кнопки подготовлены под Tilda `#popup1`. Сам поп-ап ещё не подключён: ожидается ссылка на опубликованную страницу или код Tilda. Данные не отправляются.
- Локальные шрифты Manrope с лицензией OFL.

## Мини-шоурум

Полноэкранный фото-тур по кухне: камера «летает» по реальным фотографиям, параллакс по карте глубины даёт ощущение объёма, детали открываются карточками. Настоящей 360°-панорамы нет, и она не имитируется.

- До нажатия «Открыть мини-шоурум» страница грузит только превью (~50 КБ). `showroom/showroom.js`, `stage.js`, стили и изображения подключаются после клика.
- Первая сцена: AVIF 1800 px (~60 КБ) + карта глубины (~15 КБ), затем в фоне подгружается версия 3400 px для приближения (~200 КБ). Соседние точки подгружаются заранее; при `saveData` и менее 4 ГБ памяти полноразмерные кадры не грузятся. WebP — запасной формат.
- `showroom/stage.js` — рендер: WebGL2 с параллаксом, запасной режим на 2D canvas. Параллакс реагирует на мышь, наклон телефона и медленно «дышит» сам; при `prefers-reduced-motion` отключается.
- Жесты: перетаскивание, колесо мыши и pinch для приближения, двойной клик/тап, стрелки и `+`/`-` с клавиатуры, Esc закрывает.
- Шесть кухонь: Structura 425, Cadra 746, Nordic 793, Senso 499, Structura 409 и Structura 419. Каждая собрана из фото в `showroom/source/<кухня>/`: две точки съёмки (у Structura 409 одна), шесть (у 409 пять) станций камеры, 6–8 карточек деталей, вырезанных из исходников. У Structura 425, Nordic 793 и Senso 499 есть кнопка «Оживить сцену» (те же кадры с людьми, совпадают пиксель в пиксель), у Structura 409 «Вечерний свет».
- Кадры с официальных 5K-фото грузятся в двух размерах (1800 и 3400 px). Сгенерированные кадры (1,5K) грузятся в одном размере, приближение у них ограничено.

Данные кухонь — `showroom/config.js`: фото, станции камеры (`pose`: центр и зум для десктопа и мобильного), точки (`x`/`y` в % от фото) и карточки деталей. Тексты карточек описательные (по тому, что видно на фото), подтвердите их с салоном.

Подготовка ассетов: `python3 tools/build_showroom_assets.py --depth-model model-small.onnx` (MiDaS v2.1 small, ONNX; скачивается отдельно, в репозитории не хранится; нужны `pillow`, `numpy`, `opencv-python-headless`, `onnxruntime`). Скрипт создаёт `showroom/structura-425/*`, карты глубины и `showroom/assets-meta.js`.

События отправляются в `dataLayer` и `gtag`, если они доступны, и всегда дублируются в `showroom:analytics` на `document`. Добавлено `showroom_live_toggle`.
