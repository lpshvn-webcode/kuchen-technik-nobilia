# Küchen Technik × Nobilia

Адаптивный лендинг на русском языке. Статический HTML, CSS и JavaScript; сборка и сервер приложений не требуются.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root). index.html лежит в корне. Все пути относительные, поэтому сайт работает по адресу https://OWNER.github.io/REPOSITORY/.

Для локального просмотра:

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173.

## Возможности

- Пять коллекций Nobilia с фотографиями и модальными галереями.
- Три визуальных направления с передачей выбора в форму.
- Мобильное меню, вкладки, FAQ, клавиатурная навигация.
- Локальная валидация демонстрационных форм. Данные не отправляются и не сохраняются.
- Локальные шрифты Manrope с лицензией OFL.

## Перед коммерческим запуском

Нужны контакты салона, оригинальные логотипы, согласованная политика обработки данных и получатель заявок. Подробнее в EDITORIAL.md. Фотографии Nobilia и сведения об источниках находятся в sources.json; права на их использование должны быть подтверждены владельцем.
