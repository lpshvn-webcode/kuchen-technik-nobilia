# Küchen Technik × Nobilia

Адаптивный лендинг на русском языке. Статический HTML, CSS и JavaScript; сборка и сервер приложений не требуются.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root). index.html лежит в корне. Все пути относительные, поэтому сайт работает по адресу https://OWNER.github.io/REPOSITORY/.

Для локального просмотра:

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173.

## Возможности

- Четыре кухни, предоставленные заказчиком, в двух встречных движущихся лентах: одно фото и название в карточке.
- Интерактивный мини-шоурум внутри страницы: подготовленные ракурсы, ограниченный осмотр, точки перехода и детали. На desktop карточки открываются справа, на mobile — снизу.
- Конструктор: независимый подбор верхних фасадов, столешницы с фартуком и нижних фасадов. Три отделки каждой зоны, 27 сочетаний; выбранное сочетание передаётся в контекст обращения.
- Мобильное меню, FAQ, клавиатурная навигация.
- Кнопки подготовлены под Tilda `#popup1`. Сам поп-ап ещё не подключён: ожидается ссылка на опубликованную страницу или код Tilda. Данные не отправляются.
- Локальные шрифты Manrope с лицензией OFL.

## Мини-шоурум

До нажатия «Открыть мини-шоурум» страница загружает только адаптивное превью. `showroom/showroom.js`, конфиг, viewer и изображения ракурсов подключаются после клика. Сначала загружается первый ракурс, затем соседние по графу переходов. Ракурсы хранятся в `showroom/interactive/` в WebP с JPG fallback; превью также имеет AVIF.

Данные четырёх кухонь находятся в `showroom/config.js`. Viewer изолирован в `showroom/image-view-adapter.js`: UI, навигация, hotspots и аналитика не зависят от способа отображения сцены. На мобильных устройствах широкие кадры дают увеличенный диапазон drag/pan, а пространственные стрелки помогают осматривать сцену. Свободного вращения на 360° нет.

План подготовки согласованной 13-кадровой yaw-последовательности для будущего frame-scrubbing хранится в `showroom/asset-generation-manifest.json`. Пока таких ракурсов нет, viewer использует честный wide-image pan и переходы между реальными фотографиями.

События отправляются в `dataLayer` и `gtag`, если они доступны, и всегда дублируются в `showroom:analytics` на `document`.
